# My Portfolio

Personal portfolio website (single-file HTML/CSS/JS, no build step).

## Run locally
Open `index.html` in any browser.

## Edit your details
Open `index.html`, scroll to the bottom and find `EDIT THIS BLOCK`. Change the text inside the `ME` object (name, email, links, about, skills, projects, journey, quotes).

## Deploy
Settings -> Pages -> Deploy from a branch -> `main` / root.
